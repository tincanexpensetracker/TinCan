# TINCAN — Website

The official website for **TINCAN**, a friendly savings, budgeting and expense-tracking app.

🔗 **Live site:** https://tincanexpensetracker.github.io/TinCan/

## Pages

- **Home** (`index.html`) — what TINCAN does, its features, and how it works
- **Privacy Policy** (`privacy.html`)
- **Terms of Service** (`terms.html`)
- **Delete your account & data** (`delete-account.html`) — the account-deletion URL required by
  the Google Play Console listing; keep it reachable and in sync with the in-app deletion flow
- `googleb2be9e01e1a8da4a.html` — Google Search Console site-verification token/

## About

Static site hosted on GitHub Pages — no build step, no dependencies. Each page is
self-contained HTML with a built-in light/dark theme.
